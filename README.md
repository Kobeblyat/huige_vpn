# 灰哥VPN (huige_vpn)

灰哥VPN Windows 官方 PC 客户端，基于 Flutter & Mihomo 内核深度定制开发，提供高速、稳定、安全的用户连接体验。

## 🌟 功能特性

- **智能分流与节点测速**：支持规则分流、全局模式与直连模式，内置低延迟节点自动测速与选择。
- **系统代理与虚拟网卡 (TUN)**：深度适配 Windows 10/11，支持无缝管理员提权切换 TUN 虚拟网卡。
- **专属账户系统集成**：一键登录灰哥VPN账户，自动校验套餐有效期并同步导入专属订阅。
- **GitHub 自动更新与镜像加速**：内置多条高速 GitHub 加速镜像通道（可自由选择与自定义），实现秒级静默升级与完整性校验。
